# EduFlow Suite

Create a comprehensive full-stack School Management System (Web + Mobile responsive) based on the following specification. Build a modern operational platform with role-based authentication (Admin, Teacher, Student, Parent, Accountant, Librarian, HR, Receptionist, Transport Manager), central PostgreSQL database, responsive dashboard, branding placeholders, and all modules described by the user including Student, Academic, Attendance, Teachers, Timetable, Exams, Finance, Communication, Transport, Library, Health, Reports, Notice Board, Parent/Student Portal, Staff, ID Cards, Settings, Roles, Hostel, Inventory, Admissions, Leave, Events, Assignments, Grading, Behavior, Alumni, Canteen, Documents, Backup, Multi-branch, Custom Permissions, API integrations, Alumni portal, Fundraising, Virtual Classroom, Live Classes, E-learning Hub, Career Counseling, School Shop, Payment Gateways, and landing page CTAs 'Book a Demo Today' and 'Request a Tour'. Use a modern professional UI with analytics dashboards and mobile-first responsive design. Leave branding configurable for school name and colors.
